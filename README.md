DIGITAL LOST & FOUND ITEMS MANAGEMENT SYSTEM
1. Project Description
The Digital Lost & Found Items Management System is a web-based
application that helps people report, search, and manage lost and found
items.

Users can submit details about lost or found belongings, search reported
items, view item information, and delete reports.
2. Technologies Used
- HTML: Creates the structure of the web application.
- CSS: Provides styling and responsive design.
- JavaScript: Handles application functionality and user
  interactions.
- Browser Local Storage: Stores item reports in the browser.
3. Features
- Report lost items.
- Report found items.
- Enter item name, category, location, date, contact number, and
  description.
- Search items by name, category, location, or description.
- Filter lost and found items.
- View complete item details.
- Delete item reports.
- Display total reports, lost items, and found items.
- Save reports using browser Local Storage.
4. Project Requirements
Hardware Requirements
- Computer or laptop
- Minimum 4 GB RAM
- Basic processor
Software Requirements
- Windows 10/11 or another supported operating system
- Visual Studio Code or any text editor
- Google Chrome or another modern web browser
5. How to Run the Project
1. Open the project folder in Visual Studio Code.
2. Locate the index.html file.
3. Right-click the file and choose Open with Live Server (if the
   Live Server extension is installed).
4. Alternatively, double-click index.html to open it directly in a
   web browser.
6. Project Structure
Digital-Lost-and-Found/
└── index.html
7. How to Use
1. Open the application in a web browser.
2. Go to Report Item.
3. Select Lost Item or Found Item.
4. Enter the item name, category, location, date, contact number, and
   description.
5. Click Submit Report.
6. View submitted reports in the Reported Items section.
7. Use the search box and filter to find specific reports.
8. Select View Details to see the complete report.
9. Select Delete to remove a report.
8. Data Storage
The application uses JavaScript Local Storage to save reports in the
browser. The storage key is lostFoundItems. Data is stored locally in
the browser and is not shared automatically with other users or devices.
9. Limitations
- There is no user login or registration.
- There is no centralized database.
- Reports are stored only in the browser's Local Storage.
- Data is not automatically synchronized between devices.
10. Future Enhancements
- Add user registration and login.
- Integrate a backend and MySQL database.
- Add an administrator dashboard.
- Allow users to upload item images.
- Add email or SMS notifications.
- Implement secure user authentication.
11. Conclusion
The Digital Lost & Found Items Management System provides a simple
platform for reporting and searching lost and found belongings. It
reduces manual effort and makes item reporting and management easier
through a user-friendly web application.

Developed using: HTML, CSS, JavaScript, and browser Local Storage.
